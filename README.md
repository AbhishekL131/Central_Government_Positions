# 📌 Central Government Positions  

## 🔍 Overview  
**Central Government Positions** is an AI-powered web application that provides insights into the **roles and responsibilities** of various **central government officials** such as the **Prime Minister, Home Minister, Finance Minister**, and more.  

It leverages **Gemini LLM 🤖** via **LangChain 🔗** to generate **accurate, contextual responses**, presented through an **interactive Streamlit UI 🌐**.  

---

## 🎯 Features  
✅ **Ask & Learn** – Get AI-generated insights on government roles 📜  
✅ **Powered by Gemini AI 🤖** – Generates structured and factual responses  
✅ **Interactive UI 🖥️** – Built using **Streamlit** for an intuitive experience  
✅ **Real-time Query Handling ⚡** – Get instant responses  
✅ **Scalability 📊** – Expandable to include more government structures  

---

## 🛠️ Tech Stack  
- **🤖 LLM:** Google Gemini  
- **🔗 LangChain:** For AI processing  
- **🌐 Streamlit:** For the frontend UI  

---
